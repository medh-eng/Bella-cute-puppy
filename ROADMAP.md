# Bella — The Cute Puppy — Roadmap

3D virtual-pet game for Android / Google Play: gentle, ad-free, purchase-free, offline.

Progress checklist for the Repo Command Center app (`- [x]` done, `- [ ]` remaining). Written 2026-11-24 from this repo's own docs; edit freely, and keep it current when work moves.
