# Intake 23 Nov 2026 - ten more 3D models

Source: Pon's folder "bella aseets/bella 3d model fbx files" (Triple 3D, same terms as the 19 Nov models, see CREDITS.md).
Processing: `python tools/pipeline/reduce_prop.py <G-xx.fbx> unity-project/Assets/Resources/Props <name> 1600` (needs `bpy`, Python 3.11: `uv venv --python 3.11` then `uv pip install bpy pillow`).
Each source was ~50,000 triangles / 4096 px; now ~1,600 triangles and a 512 px colour texture (about 0.17 MB each). 1,600 instead of 2,500 so Resources stays under 60 MB (now 59.9).

| File | Becomes | Where it is used |
|---|---|---|
| G-12 | `windowbox` | tulip box on the window sill (`Room.BuildSillAndFloorToys`) |
| G-15 | `toy_rope` | tappable/movable floor toy, id `rope` (Room) |
| G-17 | `toy_teddy` | tappable/movable floor toy, id `teddy`, left of the armchair (Room) |
| G-18 | `toy_frisbee` | the disc in the Frisbee mini-game; flat picture is the fallback |
| G-21 | `food_treat` | shown in front of Bella when the treat meal is bought (`FeedingActivity`) |
| G-22 | `food_fancy` | same, for the fancy meal |
| G-23 | `food_cake` | Bella's-birthday decoration in the `floorR` spot, replaces that picture (`FestiveDecor`) |
| G-27 | `shampoo` | on the floor beside the bath tub (Room) |
| G-43 | `hat_crown` | the gold crown on Bella's head (`Accessories`); the rose crown keeps the old built shape |
| G-71 | `friend_bird` | **Pip**: perches on the window sill by day, bobs and hops, tap = sparkles + hearts + yip + 3 happiness (`Ambience`) |

Not used: `G-21.glb` (same model as G-21.fbx). Models that were already in the game (G-01..G-05, G-07..G-11, G-16) were not redone.
Every model is optional: when a file is missing the old look is built exactly as before.
